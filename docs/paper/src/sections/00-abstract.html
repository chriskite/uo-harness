Abstract

We describe uo-harness, an AI agent harness that plays the Ultima Online free shard Outlands through a localhost proxy between the stock game client and the server. Deterministic Python runners do the reflex work: walking, chopping trees, fleeing, storing. They act on a world model built from server packets and a single SQLite memory that every part of the system shares. A Bayesian planner (Thompson sampling over lumber spots, with a renewal-reward trip size under competing death, sent-home and theft hazards) decides where to go and how long to stay. An LLM overseer, the Seer, sits outside the inner loop on a database message bus. It wakes at junctures, talks to the owner through a web visualizer and Telegram, and consults a knowledge base distilled from the community Discord through hybrid semantic search. The whole system was built in ten days by one person directing AI coding agents, mainly Claude Opus, with Kimi and Sonnet for some jobs: 568 human prompts became 389 commits and about 56k lines of Python. Over 88 logged-in hours the harness chopped 32,676 logs, stored 23,003 boards from 86 recorded lumber trips, raised a character's Lumberjacking from 50.1 to 95.6, answered 67 of 67 harvest CAPTCHAs, and died 12 times, three of them to the same player-killer. We report what worked, what we got wrong first, and what it was like to let the agents work out most of the implementation decisions.
