Glossary

Ultima Online, Outlands and project jargon used in this paper, alphabetically. Packet ids are in .

Agent gate
The harness's pause button, kill switch, forced-break timer (about every 2 h, jittered) and 8 h/day budget. The proxy checks it before every injected packet; the human's own traffic is never gated.
Aspect
Outlands' gear-specialisation system. A full set of Harvest-aspect armor (hue 2086) adds effective skill and a chance of double yield, so the lumber runner checks it before every trip.
Bastet
A mounted player killer whose title line read "Serial Killer [Prevalia]". Bastet killed our lumberjacks three times on 10-02 and 10-03, which is where recall-on-sight came from ().
Board / log
Trees yield logs; logs are converted into boards, the stored product. On 2026-10-05 a regular board was worth about 26.8 gp.
Captcha
Outlands' anti-automation dialog for harvesters: a gump with a number to type, about every 5–10 minutes. Three wrong answers block harvesting for 6 h.
Characters
TestWorth (Test Shard, from 09-28), Hackworth (fresh Young character from 10-01), Shackleworth (an Arcane Mage, 10-03), Outland Dan (DTF guild, from 10-04), and Logan Wolf (holds the rental room; 0.37 h on 10-05, never agent-driven).
ClassicUO
The open-source UO client. Outlands ships its own fork of it, compiled with NativeAOT and with Razor built in.
Cliloc
The client's numbered table of localised strings (Cliloc.enu). Many server messages arrive as a cliloc number with arguments, e.g. 502406, "This book needs time to recharge."
ctl
harness/ctl.py, the command-line API through which the Seer (or a human) reads state, runs tasks, acts in game and answers junctures. Every call prints exactly one JSON object.
DTF
Outland Dan's guild. Its guild house holds a rune library of 36 tomes and 839 runes, and a house steward that leads to Logan Wolf's rental room, Dan's home.
Fastwalk key
A 32-bit token carried in each walk packet. The server hands tokens out (login usually ends on 8 and most re-arms carry 1, but the server also sends other small values; the proxy copies whatever it was given) and Outlands, unlike stock server emulators, checks them.
Gump
A server-defined dialog window: a layout of text, images, buttons and text entries. Runebooks, room menus, shelves and the captcha are all gumps.
Heat of Battle
The state after fighting a player, during which recall is blocked. It is one reason the harness never attacks players.
Juncture
An event on the overseer bus (table junctures) that can wake the Seer: a threat, a failed or finished task, nearby speech, a captcha, a death, possible staff. The store held 314 juncture rows by 2026-10-05.
Landing
The tile a recall arrives on. The planner picks the rune whose landing is nearest the chosen grove and remembers landings that went wrong.
Laya
An encoder model (ModernBERT-large, 421M parameters) that answers yes/no questions about a line of text in one forward pass. Here it triages speech heard near a harvest job ("is this an attendance check?"), served locally on the GPU and fine-tuned once.
Moongate
A public teleporter with a destination menu. On Shelter Island, taking one asks the player to renounce Young status.
Multi
A many-piece structure, usually a house, that the server sends as one item whose graphic is an index into multi.mul. The harness expands multis into walls and doors so that routes stop running into houses.
NativeAOT
.NET's ahead-of-time compilation to native machine code. The Outlands client is not a managed assembly, so there is no plugin loading and no IL decompiler shortcut; reverse engineering went through Ghidra and the binary's reflection metadata.
Notoriety (noto)
A per-mobile reputation code in the mobile-update packet: 1 blue (innocent), 2 green (ally; the harness treats it as blue), 3–4 grey (attackable, criminal), 5 orange, 6 red (murderer), 7 invulnerable (NPCs, vendors, staff).
NPD
The New Player Dungeon on Shelter Island, where TestWorth's death demo took place and where the hunt runner first fought.
omp
The AI coding-agent harness that wrote this project. The Seer also runs on it, as an omp session or subagent.
Razor
The UO assistant (macros, hotkeys, scripts) built into the Outlands client and the only sanctioned automation. Razor scripts can't walk on Outlands (removed 2023-07), and Outlands can gate them from the server.
Recall
A Magery teleport to the location marked on a rune, cast as a spell or spent from a book's charges. It takes about 2 s and can be disturbed by damage. It is the harness's escape and its way to and from work.
Red / PK
A player killer. "Red" refers to notoriety 6, the murderer's name colour. Our threat model doesn't treat colour as proof either way: a thief looks blue until the moment of the steal.
Rental room
Outlands' inn-room housing. Nobody can follow you in and no recall reaches inside, so since 10-04 lumber trips end there.
Rune, runebook, rune tome
A rune marks one location to recall to. A runebook holds runes, recall charges and a default rune. A rune tome is a larger Outlands book (up to 26 rows) that opens only within 2 tiles.
Rune library
A collection of locked-down tomes others can use: the public Cambria library (14 tomes, 360 runes, including the 359 numbered Witcher runes) and the DTF guild house (36 tomes, 839 runes).
Secure chest
A locked-down container in the rental room that only its owners can open. Boards went there until the stockpile took over.
Seer, the
The LLM overseer: an omp agent session that supervises the deterministic runners through ctl, wakes on junctures, and talks to the owner in the viz and on Telegram. It was named on 2026-10-03 and given Hawkwind's voice ().
Shelter Island
Outlands' new-player island. Harvesting there needs Young status, halves the harvest chance and caps skills at 80, but no hostile player actions are possible.
Smart Harvest
Answering the hatchet's target cursor with yourself instead of a tree: the server then chops whatever harvestable tree is nearby. Adopted 2026-10-04.
Stationary Penalty
An Outlands rule: after a recall or teleport, or after about 5 minutes standing still, harvesting fails until you walk 5 steps.
Steward
The house NPC whose context menu ("Room" → "Visit Other Rooms") leads into a house's rental rooms. Leaving the room by its door returns you to the steward.
Stockpile
A Resource Stockpile: Outlands storage for raw materials, added to the room on 2026-10-05. It holds boards by kind and read 8,693 boards after the chest was emptied into it.
Storage shelf
A container that keeps a per-character loadout: "Resupply" tops the backpack up to it, "Restock" puts surplus and spent items back.
Test Shard
Outlands' public test server. Houses and inn rooms are wiped every day at midnight UTC. The project started there with TestWorth before moving to what we believe is the live shard.
Trapped pouch
A pouch that explodes when opened. The runner stashes logs in one so that a thief who snoops it sets off an alarm: "a delay plus an alarm, not a lock".
Walk sequence
The 8-bit counter in every walk packet: starts at 0, wraps from 255 to 1, and the server accepts only the value it expects next. The proxy keeps one shared ladder for the human's and the agent's walks.
WinDivert
A Windows packet-diversion driver. The harness uses it as a small user-space NAT that redirects the client's port-2593 connection to the local proxy, because the client ignores its own server settings.
Witcher runes
A community rune set laid out by a player called Witcher for treasure hunting: about 359 numbered runes spread across the wilderness, publicly available in Cambria. They became the lumber planner's gateway to the whole map.
Young
New-player status. It protects starting items and gives access to Shelter's bank, vendors and harvesting. It is kept until you leave Shelter Island or renounce it, and renouncing is permanent.
